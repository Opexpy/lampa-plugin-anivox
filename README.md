# Плагин AniVox для Lampa

Плагин добавляет в приложение Lampa источник **AniVox**[](https://anivox.fun) — просмотр аниме онлайн.

## Возможности

- Поиск аниме по названию
- Просмотр списка последних обновлений
- Получение прямых ссылок на видео (в большинстве случаев через iframe-плееры)
- Поддержка пагинации (частично)

## Установка

1. Откройте Lampa  
2. Перейдите в **Настройки → Плагины → Добавить плагин**
